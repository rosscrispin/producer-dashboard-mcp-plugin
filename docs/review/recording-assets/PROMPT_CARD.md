# The Library MCP review prompt card

Use this card beside the local screen recorder. The prompts match the review cases in the root manifest.

## Positive cases

1. `Show me my tracks that are in the tree stage.`
2. `Find my finished tracks with no open to-dos.`
3. `Move the track named 'Example Track' to the finished stage.`
4. `Create a share page for my finished tracks titled 'Review Set'.`
5. `Export a CSV split sheet for my 'Releases' bucket.`

## Negative cases

1. `What is the weather in Brisbane today?`
2. `Delete every audio file from my computer.`
3. `Create a new song in my library and upload this audio file.`

## Capture notes

- Replace `Example Track` and `Releases` with disposable reviewer data before recording.
- Keep account email addresses, collaborator contact details, OAuth codes, tokens, and private audio out of the frame.
- Pause after each prompt so the selected tool and the user-visible result are readable.
- Mark the matching permission state in the recording notes when a write or export case is run.
